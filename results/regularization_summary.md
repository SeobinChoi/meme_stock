# 정규화 기법 실험 결과 요약

## 📊 **실험 설계**

- **Ridge Regression**: L2 정규화로 가중치 축소
- **Lasso Regression**: L1 정규화로 피처 선택
- **Elastic Net**: L1 + L2 정규화 조합
- **하이퍼파라미터 튜닝**: Alpha와 L1 ratio 최적화
- **평가 지표**: IC (Spearman), Hit Rate, R²

## 📋 **핵심 발견**

### 1. **정규화 효과**
- ❌ **모든 정규화 기법이 성능을 저하시킴**
- 테스트 데이터에서 음수 IC 관찰
- 과적합보다는 **과소적합** 문제가 더 심각

### 2. **모델별 특성**
- **Lasso**: 가장 강한 정규화, 최고 성능
- **Ridge**: 가장 약한 정규화, 중간 성능
- **Elastic Net**: 중간 정도 정규화, 중간 성능

### 3. **피처 중요도 일관성**
- **`log_mentions`**: 모든 모델에서 상위 중요도
- **`vol_reddit_attention`**: 모든 모델에서 상위 중요도
- **`reddit_ema_3`**: Ridge와 Elastic Net에서 높은 중요도

### 4. **하이퍼파라미터 민감도**
- **Lasso**: Alpha > 0.001에서 모든 피처 제거
- **Ridge**: Alpha 변화에 상대적으로 안정적
- **Elastic Net**: L1_ratio에 따라 피처 선택 정도 조절

## 🎯 **논문적 시사점**

### 1. **정규화의 한계**
- **과적합 문제**보다는 **모델 복잡도 부족**이 주요 문제
- Reddit 피처의 **약한 신호**로 인해 정규화가 오히려 해로움

### 2. **피처 신호 강도**
- **EMA 계열 피처**가 가장 안정적인 신호
- **멘션 수**와 **변동성-관심도 상호작용**이 중요
- **모멘텀 피처**는 일관성 있게 중요도 상위

### 3. **모델 선택 전략**
- **Lasso**가 가장 효과적인 정규화 방법
- **피처 선택**이 **가중치 축소**보다 효과적
- **과소적합** 방지를 위한 **모델 복잡도 증가** 필요

### 3. **모델링 전략**
